# TeachSim V6.7 — Specialist review pack

**Status: draft for expert review. Not independently validated.** This describes a fictional simulation only. It does not establish an appropriate protocol for any actual learner.

## Proposed observable decision rules

| Learner outcome after Wait | Teacher action in this demonstration | What Review checks |
|---|---|---|
| Correct response (independent or prompted) | Acknowledge and continue; avoid additional prompts | Acknowledgement after completion; no unnecessary prompts |
| No response | Use the next agreed prompt: gestural, then model | Prompt order and observing after each prompt |
| Incorrect response | In this **provisional** protocol, use the next agreed prompt | Whether a task-specific error-correction method should instead be used **requires expert validation** |
| Still incomplete after model | Pause and consult the trainer/plan; do not mark completed | Unresolved step remains incomplete, with a recorded pause |

**Training caveat:** Least-to-most hierarchies often include a controlling prompt designed to produce a correct response. Here the demonstration stops at modelling, which may not be controlling for a given task or learner. Expert review should determine whether this branch and its use in a teacher trial are suitable.

## Specialist questions

1. Are all examples of **incorrect** vs **no response** genuinely distinct and observable, and do the examples match the step context?
2. Is the fixed hierarchy (independent opportunity → gesture → model) appropriate for each target skill?
3. Does an incorrect response require correction different from the next prompt in the hierarchy?
4. What controlling prompt, if any, should follow modelling, and under what safeguards/permissions?
5. Is the feedback appropriately constrained to **button-choice patterns**, without implying teaching competence?

## Scenario-by-scenario checking

Each listed variation uses the observed response after instruction (I), gesture (G), and model (M). A correct response ends the step; unresolved means pause.

## V6.9 interface clarification
The Gestural and Model buttons now show the underlying action immediately below the prompt type (task-specific in Guided, generic in Experienced). Initial direction and response opportunity are visibly outside the prompt hierarchy. **Acknowledge success is not a prompting level**; it is presented separately as a post-response teaching action. The new task-workspace vector graphics are simplified representations of materials rather than literal demonstrations of the exact learner response; validate teacher interpretation of each visual in a small specialist usability review.
